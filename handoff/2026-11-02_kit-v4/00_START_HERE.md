## Run the agents

All four can run at the same time. Each one works in its own copy of the project, so none of them touches the main folder, which a writing run may be using.

For each brief:
1. Start a **new** Antigravity conversation with your builder model.
2. Set the workspace to `D:\Project Recess`.
3. Open the brief file, copy all of it, and paste it into the **chat box**.

Each one ends with a READY or BLOCKED line. Paste those reports to Claude.

## When the writing run is finished

Merge nothing while a writing run is going. When it has finished, tell Claude. The kit v4 branch can then go into `master`, after one check.
